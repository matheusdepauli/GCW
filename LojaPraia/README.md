# Loja da Praia - Site Profissional

Site institucional e de reservas para aluguel de equipamentos de praia e aulas de surf.

## Funcionalidades implementadas

- Hero turístico com proposta comercial clara
- Catálogo completo com filtros por categoria e busca por nome
- Seção de aulas de surf por nível (iniciante/intermediário/grupo)
- Formulário de reserva/agendamento online
- Persistência das reservas no navegador (LocalStorage)
- Painel com últimas reservas registradas
- Bloco de clima e condições do mar em tempo real (Open-Meteo)
- Galeria visual com fotos de praia e surf
- Integração com Google Maps, WhatsApp e Instagram
- Layout responsivo para desktop, tablet e celular

## Como executar

Abra o arquivo `index.html` em qualquer navegador moderno.

Opcionalmente, rode um servidor local:

```bash
python -m http.server 8080
```

Depois acesse `http://localhost:8080/loja-da-praia-site/`.
